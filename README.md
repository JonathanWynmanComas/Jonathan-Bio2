# Jonathan-Bio2

## Project Overview
This project is an enhanced **Student Bio webpage** created for Homework 2.  
The webpage is built using **HTML and external CSS** and demonstrates core front-end concepts such as navigation bars, flexbox layouts, responsive design, and clean styling.

The goal of this assignment is to practice structuring a webpage, organizing content, and making it responsive across different screen sizes.

---

## Technologies Used
- HTML5  
- CSS3 (External stylesheet)
- Flexbox
- Media Queries

---

## Project Features

### Navigation Bar
- A fixed navigation bar with links to:
  - About section
  - Projects section
  - Contact section
- Allows smooth navigation within the page

###  About Section
- Displays student name, image, and short biography
- Clean layout with centered content

###  Projects Section
- Uses **Flexbox** to organize project cards
- Each project includes:
  - Project title
  - Short description
  - Link to GitHub repository (if available)

###  Contact Section
- Lists email, GitHub profile, and portfolio information

###  Responsive Design
- Media queries adjust layout for smaller screens
- Background color changes on smaller screen sizes
- Navigation bar and project layout stack vertically on mobile devices

---

##  Responsive Behavior
- Desktop: Projects displayed in a row using flexbox
- Tablet/Mobile:
  - Navigation links stack vertically
  - Projects stack in a single column
  - Background color changes for better visual feedback
